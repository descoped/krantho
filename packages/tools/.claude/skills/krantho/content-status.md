# /kt-status

Show all content with current status, grouped by collection.

## Steps

1. Run the status script: `bash scripts/status.sh`
2. Display results grouped by collection
3. Show summary counts per status

## Output Format

```
Content Status

pages/ (4 files)
  published  home.md
  published  about.md
  published  features.md
  draft      pricing.md

blog/ (3 files)
  draft      2026-03-28-launch.md
  draft      2026-04-01-schemas.md
  published  2026-04-05-seo.md

Summary: 4 published, 3 draft
```
