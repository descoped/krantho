A small patch release for static sites on GitHub Pages.

## Fixed

- **The image cache follows your settings.** The starter's Pages workflow keys its image cache on the images, `krantho.config.ts` and the lockfile, so copies remade after a quality change or a krantho upgrade are kept for the next deploy. See [Deploy to GitHub Pages](/docs/deploy-github-pages).
- **A site without images.** The image step writes an empty manifest, so the cache has a folder to save and the deploy log no longer warns.

## Changed

- **Dependencies** are up to date, among them SvelteKit 3.2.1 and its Node and Vercel adapters.
