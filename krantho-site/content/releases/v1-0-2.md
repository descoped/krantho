A patch release that keeps the site in step with its repository and the toolchain current.

## Fixed

- **Removed files take their pages with them.** When a deploy no longer has a content file, the import deletes its document. A document an editor changed in Studio is kept, and the import takes a checkpoint first. Before, a deleted or renamed file left its page live and in the sitemap.
- **New projects build SQLite under pnpm.** `create-krantho` allows `better-sqlite3`'s native build on pnpm 10 and on pnpm 11 and later.

## Changed

- **SvelteKit 3.** The scaffolder and the examples pass the adapter to the Vite plugin, and the documentation follows. `@krantho/ui-svelte` now ships a compiled build.
- **postgres.js 4** is the supported Postgres client.
- **Dependencies and tools** are at their latest versions: pnpm 12, TypeScript 7 (6 for SvelteKit packages), Vitest 5 and Node 26.
