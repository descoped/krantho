A patch release for sites that install krantho from npm.

## Fixed

- **Next.js sites start.** `@krantho/server-next` loads in a project installed from npm. In 1.0.0, every page, the API and Studio failed with "Cannot find module next/server".
- **Studio is found under every package manager.** `@krantho/server` now depends on `@krantho/studio` and finds it among its own dependencies, so `/studio` loads under pnpm's strict layout as well.

## Changed

- **Every package on npm describes itself**, and is published from this repository's release workflow through npm trusted publishing, with provenance.
- **Dependencies** are updated to their patched versions.
- **The documentation** lists [every package](/docs/packages) with what it is for.
