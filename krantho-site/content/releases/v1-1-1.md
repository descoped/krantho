A patch release that lets a static site publish the docs folder a project already has, so the same files read well on GitHub and on the site.

## Added

- **README.md as the home page.** A collection's `indexFile` names the file read as its home page, such as `README.md`, the file GitHub shows for a folder.
- **Links between files.** On a static site, `[Setup](setup.md#install)` goes to the setup page, and `![Flow](images/flow.png)` is served from the site's root. Pass `site.rendering` to `initServerLoader()`. See [Links between files](/docs/package-static#links-between-files).
- **Publishing a repository's docs.** [Deploy to GitHub Pages](/docs/deploy-github-pages#publish-a-repositorys-existing-docs) shows a site in a folder of a project's repository that reads the project's `docs/`.

## Changed

- **Images sized in HTML.** The `src` and `href` of `<img>` and `<a>` tags in markdown follow the same rules as markdown links, so `<img src="images/flow.png" width="340">` works under a base path.
- **`@name` in prose.** A static site's pages follow `content.atNotation`, so `false` leaves `@name` as written.
- **The static starter** writes no `.env`, and wide tables scroll on their own.
