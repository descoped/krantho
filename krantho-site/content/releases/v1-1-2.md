A patch release that makes a static site's images light: each one is served at the width it is shown, in a modern format.

## Added

- **Image copies for static sites.** `prepareImages()` gives each image in `public/` AVIF and WebP copies at the widths the krantho server serves its media at, and the static starter runs it on every build. Only changed images are copied again. See [Images](/docs/package-static#images).
- **Images as `<picture>`.** Each markdown image with copies renders as a `<picture>`, so the browser picks the smallest copy that fits. The original stays as the fallback, with its width and height, so the page does not shift as it loads. Images after the first load lazily. Set `images.sizes` to your content column's width.

## Changed

- **Agent skills.** The krantho plugin's skills cover static sites on GitHub Pages, including publishing a repository's existing docs folder.

## Fixed

- **The `@krantho/static` README** shows `initServerLoader(site.loader, site.rendering)`, so links between files work when you copy it.
