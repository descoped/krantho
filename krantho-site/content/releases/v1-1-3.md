A patch release that makes a static site's images lighter on every screen, and its deploys faster.

## Changed

- **Widths for every screen.** A static site copies its images at widths from 320 to 2048 pixels, about 1.2–1.5× apart, so phones, tablets, laptops and desktops each load a copy close to the size they show, in portrait and landscape. A content column on a 2× screen now loads a 1536-pixel copy instead of a 2048-pixel one. Give your own list with `prepareImages({ widths })`. See [Images](/docs/package-static#images).
- **Faster deploys.** Copies are kept by the content of their image, not its date, and the static starter's workflow caches them, so a deploy encodes only new and changed images. Each image is decoded once for all its copies.

## Fixed

- **Images sized in markdown.** `<img width="340">` gets `sizes="340px"`, so the browser loads a copy for 340 pixels rather than for the whole column.
- **An unreadable image** is served as it is, with a warning, instead of failing the build.
- **The starter's `.gitignore`.** Only a static site lists `public/_krantho/`.
