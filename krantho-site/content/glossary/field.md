---
title: Field
definition: One named value of a document, such as its title or description, validated by the collection's schema.
docs-page: content-fields
status: published
---

In a Markdown file, fields are written as frontmatter; inside the CMS — the API, Studio and persistence — they are called fields. The API returns them as `fields.title`, `fields.description` and so on. `status` and `locale` are system fields that move into the document's metadata.
