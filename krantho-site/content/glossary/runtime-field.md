---
title: Runtime field
definition: A field an administrator adds to a collection from Studio or the CLI, next to the fields defined in code.
docs-page: studio
status: published
---

Runtime fields are additive: they extend a collection, but a field its code defines cannot be changed or removed at runtime. Studio shows them in the same form as the code-defined fields. When a field proves permanent, move it into the collection's schema in code.
