---
title: Page template
definition: The route in your app that reads content and turns it into a page.
docs-page: templates
status: published
---

In Next.js a page template is a server component under `app/`; in SvelteKit it is a route with a server load; in Express it is a handler that renders HTML. It reads the published version of a document and decides the layout. Krantho has no page builder: layout is your code, content is the editor's.
