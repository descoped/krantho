If you are a collaborator on the krantho repository, yes. The plugin is distributed from that repository, which is private for now, so adding the marketplace works only with access to it. When the repository is public, the same two commands work for anyone using Claude Code.

The plugin's skills guide your coding agent through setting up krantho, modeling content, building page templates, editing content and configuring SEO.
