---
title: 'Can I install krantho from npm today?'
topic: product
order: 1
docs-page: project-status
status: published
---

No. Krantho is in active development, and its packages are not yet published to npm: installing `create-krantho` or any `@krantho/` package fails today. The install commands in the documentation describe what the first release will use.

Until then, krantho runs from source: you build the packages in the krantho repository and run one of its example apps. The repository is private for now, so this works for collaborators. The project status page has the steps.
