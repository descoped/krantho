## Admin Frontend

Studio will provide a visual editor for database-mastered content (blog posts, news). Built with React and the same `@krantho/api` endpoints that the CLI uses.

## Go CLI (krantho)

A cross-platform binary for content management from the terminal. Create, validate, enrich, and publish content — all through REST API calls.

## Timeline

These features are planned for Milestone 3 (M3). Stay tuned.
